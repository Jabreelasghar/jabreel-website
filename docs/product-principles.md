# ThinkLab Product Principles

These principles are the decision standard for ThinkLab product, design and engineering work.

1. Reliability before features.
2. Student learning before analytics.
3. Context before memory.
4. Teacher control before automation.
5. Simplicity before configurability.
6. Human judgement before AI judgement.
7. Every feature must improve the classroom experience.

When a proposed feature conflicts with these principles, the team should simplify, defer or reject it. Evidence of educational value and classroom reliability should carry more weight than novelty or technical possibility.
